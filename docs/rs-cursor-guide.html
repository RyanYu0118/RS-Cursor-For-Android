2准备工作

RS Cursor 是电脑上 Cursor 的遥控器，需要电脑和平板两端配合：

设备要求
电脑Windows 10 / 11，已安装并登录 Cursor；Node.js 20 或 22（LTS）；Git
平板Android 8.0 及以上（手机也能装，界面按平板设计）
网络平板和电脑在同一个 Wi-Fi；或者两端都安装 Tailscale 并登录同一账号（不在同一网络时推荐）

工作原理：电脑上运行一个"主机服务"（端口 4331），由它读写 Cursor 的对话。平板 App 直接连接这个主机，中间不经过任何第三方服务器，项目和代码始终留在你的电脑上。

3电脑端：安装主机服务

以下命令都在 PowerShell 中执行。

① 安装 Cursor Agent 命令行并登录

irm 'https://cursor.com/install?win32=true' | iex
agent login

安装后如果提示找不到 agent，关闭 PowerShell 重新打开再试。

② 下载并安装主机服务

git clone https://github.com/RyanYu0118/RS-Cursor-For-Android.git
cd RS-Cursor-For-Android
npm install

npm install 结束时会打印一份环境检查清单，按提示把红色项处理掉即可。

③ 设置开机自启并启动

npm run autostart:install
Start-ScheduledTask -TaskName AutoSupervise

主机会在后台运行，没有窗口，关掉 PowerShell 也不影响。用浏览器打开 http://127.0.0.1:4331/api/health，能看到返回内容就说明主机已经启动。

④ 让 Cursor 带调试端口启动（必须）

右键 Cursor 的开始菜单或桌面快捷方式 → 属性 → 在"目标"末尾加一个空格和：

--remote-debugging-port=9222

然后完全退出 Cursor（包括托盘图标），再用这个快捷方式重新打开。没有这一步，平板无法和电脑上的 Cursor 互动。

⑤ 放行防火墙（平板连不上时再做）

以管理员身份打开 PowerShell，执行：

New-NetFirewallRule -DisplayName "Auto" -Direction Inbound -Protocol TCP -LocalPort 4331 -Action Allow

4平板端：安装与连接

  1. 把 APK 传到平板上安装。系统提示"未知来源"时，允许当前文件管理器或浏览器安装应用。
  2. 查到电脑的主机地址：
    • 同一 Wi-Fi：电脑上运行 ipconfig，找到 IPv4 地址，例如 http://192.168.1.23:4331
    • Tailscale：电脑上运行 tailscale ip -4，例如 http://100.x.y.z:4331
  3. 打开 RS Cursor，在"主机地址"页填入上面的地址，点"保存并打开"。
  4. 连接成功后出现侧栏和对话界面。之后打开 App 会自动连接，断线也会自动重连。

电脑换了 IP（比如换了 Wi-Fi）也没关系：加载页会出现"重试"和"更改主机地址"按钮，平时也可以点右上角的设置按钮修改。

5功能使用

功能怎么用
侧栏左上角菜单按钮打开或收起。结构和电脑上的 Cursor 一致：Pinned 在上，下面按仓库分组，每个对话显示它在 Cursor 里设的图标和颜色。点对话即可打开。
长按菜单长按侧栏里的对话：置顶 / 重命名 / 改图标 / 标为未读 / 复刻 / 移动到 / 复制 / 归档。操作直接生效，电脑屏幕上不会弹出任何东西。
新建对话点 New Chat，或点仓库旁的 + 在该文件夹新建。发出第一条消息后，对话会在电脑 Cursor 的侧栏里悄悄出现并开始运行，电脑不弹窗、不抢焦点。第一条消息暂时不能带图片。
输入同步电脑 Cursor 正在显示同一个对话时，两边输入框实时同步。谁在打字谁优先，哪边按发送就发哪边的内容。
发消息与排队AI 忙时照样可以发，消息会进入"Queued"排队卡片，当前一轮结束后自动发出。
模型与参数点输入框右侧的模型按钮，可切换模型以及速度、上下文、推理强度等参数，和电脑共用同一个设置。
图片点输入框的 + → Files 选图发送；点已发送的缩略图可查看原图。
历史记录在对话里向上滑动，自动加载更早的消息。

6常见问题

现象解决办法
一直停在"连接中"① 电脑上打开 http://127.0.0.1:4331/api/health 确认主机在运行，没运行就执行 Start-ScheduledTask -TaskName AutoSupervise；② 确认平板和电脑在同一网络或同一 Tailscale；③ 地址要带 http:// 和 :4331；④ 按第 3 节第 ⑤ 步放行防火墙。
能连上，但消息发不到电脑的 Cursor多半是 Cursor 没带调试端口启动。按第 3 节第 ④ 步修改快捷方式，完全退出后重新打开 Cursor。
侧栏图标只显示圆点图标字体会在首次连接时下载，稍等片刻即可。在 Cursor 里没设过图标的对话本来就显示圆点。
新对话没出现在 Cursor 侧栏如果这个文件夹在 Cursor 里从没建过对话，第一轮会改在后台运行并给出提示。先在电脑上用 Cursor 在该文件夹建过一次对话，之后就正常了。
Cursor 更新后功能异常RS Cursor 依赖 Cursor 的内部机制，Cursor 大版本更新后可能需要等待适配，请关注 GitHub 上的新版本。

7安全提醒

  • 主机服务没有登录密码，访问控制靠网络本身。只在家里的局域网或 Tailscale 内使用。
  • 不要把 4331 端口映射到公网，也不要对它开启 Tailscale Funnel。
  • 默认设置下 AI 执行命令不会逐条询问。共用电脑建议在仓库目录的 .env 中设置 AUTO_POLICY=ask-on-write。
